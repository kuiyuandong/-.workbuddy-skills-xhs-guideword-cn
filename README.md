# xhs-guideword-cn

将辽宁景区**中文**导游词转化为小红书图文发布包的 Skill，专用于 2026 辽宁导游资格证口试（机考）备考内容。

## 功能

- 输入中文导游词（docx 或纯文本），生成**深蓝品牌卡 6 图**（3:4，1080×1440px）：
  - 封面 + 导游词上 / 中 / 下（全文进图卡）+ 踩分要点 + 扣分提醒（双栏）
- 输出发布包 markdown：标题评分 / 正文 / 标签 / 置顶评论 / 自检清单
- 纯矢量文字卡（零实景图、零 AI 图），无需 AI 标识

## 与英文版区分

- 本 skill 仅处理**中文**讲解稿；英文口试稿走 `xhs-guideword-en`。

## 合规要点（发布前必查）

- 专名红线（如「鞍钢」禁「安钢」）
- 极限词：史实类「第一」豁免，但需加免责声明；禁「最/唯一/顶级」
- 站外引流：正文零公众号/私信/外链，领取只走评论区置顶
- 标题 ≤20 字、正文 ≤950 字符、机考录制限时 5 分钟

红色 / 工业题材初始流量池偏小、「自见不外放」属平台常态风控，非账号违规。详见 SKILL.md 第五节。
