- 安全线：`content_end`（正文最后一行 y）须 < 底部序号圆顶沿 1190，留白充足

## 关键函数（gen_cn_template.py）

- `vgrad(h, top, bot)`：竖直线性渐变底
- `wrap_cn(text, fnt, max_w)`：中文按字符换行，自动避头点（行首标点悬挂 `PUNCT_HANG = "，。、；：？！」』）…—%"`）
- `badge / banner / bottom_title / check / warn / dot`：矢量组件（珊瑚橙 ✓、黄 △、彩色圆点）
- `sec_title / li`：小标题 + 条目（icon 可为 check/warn/dot 或 RGB 元组）
- `guide_card(num, title, paras, fname)`：导游词卡（支持【】小标题自动金色渲染）
- `point_card(num, bt_title, sections, fname)`：单栏踩分卡
- `point_card_merged(num, bt_title, left_sections, right_sections, fname)`：双栏合并卡（扣分提醒用，左=严重/一般扣分，右=加分/须知）
